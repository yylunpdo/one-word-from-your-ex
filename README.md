Entry for the [make.fun](https://make.fun) bounty
["One Word From Your Ex"](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2)
(2 USDC, winner-takes-all).

The bounty asks for exactly ONE word — the word your ex would use to
describe you — and nothing else. The judge compares words pairwise and
picks the funniest, most brutally honest one.

## Entry

**unreachable** (11 characters)

Funny at first — always busy, always somewhere else — then painfully
honest: the calls never returned, the plans never kept, the reason it
ended. One word, no spaces, no sentence.

## How it works

`main.py` is pure Python stdlib with no dependencies. It validates the
word (single lowercase word, 1–20 characters) and writes it to
`/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
